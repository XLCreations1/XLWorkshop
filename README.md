# XLWORKSHOP — GitHub Pages Site

Nature-night themed website for XLCreations Workshop.

## File Structure
```
xlworkshop/
├── index.html          ← Home page
├── maps.html           ← All maps
├── texture-packs.html  ← Texture packs & addons
├── paid-maps.html      ← Premium / Altarbound series
├── help.html           ← Install guide + version help
├── style.css           ← All styles
├── shared.js           ← Stars, fireflies, nav, animations
└── README.md
```

## Deploying to GitHub Pages

1. Create a new GitHub repository (e.g. `xlworkshop`)
2. Upload all files from this folder to the repo root
3. Go to **Settings → Pages**
4. Set source to **Deploy from a branch → main → / (root)**
5. Save. Your site will be live at:
   `https://yourusername.github.io/xlworkshop/`

## Customizing

- **Add real screenshots**: Replace the emoji placeholder divs in map/pack cards with `<img>` tags pointing to your images.
- **Update download links**: Replace any `link-center.net` / `direct-link.net` links with MediaFire direct links for best user trust.
- **YouTube embeds**: In each map card you can add an `<iframe>` embed from your YouTube channel.
- **Hiatus status**: When you're back, remove the `.footer-hiatus` div from each page footer.

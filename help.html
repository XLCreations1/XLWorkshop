📖 Guide

Help & Installation

Step-by-step guides for installing maps on Android, iOS, and Windows. Version info included.

📋

Jump to: .mcworld install · .zip install · Version matching guide · Troubleshooting

Installing a .mcworld File

✅ Recommended — Works on Android, iOS & Windows 10/11

Step 1 — Download the file

Download the .mcworld file from the download link on the map page.

Step 2 — Open the file

Tap or double-click the downloaded .mcworld file. Minecraft will launch automatically and begin importing.

Step 3 — Wait for import

Wait for the "Successfully Imported" message to appear in Minecraft.

Step 4 — Play

Go to Play → Worlds, find the map in your world list, and tap to start playing.

Installing a .zip File

Manual Method — For Older Maps

Step 1 — Download and extract

Download the .zip file and extract it using your device's file manager or a tool like WinRAR / 7-Zip.

Step 2 — Confirm extraction contents

Make sure the extracted folder contains these files directly (not nested inside another folder):

  • level.dat
  • db/ folder

Step 3 — Move the folder to the right location

Android:

Internal Storage → Android → data → com.mojang.minecraftpe → files → games → com.mojang → minecraftWorlds

Windows 10/11:

C:\Users\YourName\AppData\Local\Packages\Microsoft.MinecraftUWP_...\LocalState\games\com.mojang\minecraftWorlds

Tip: Press Win + R and type %localappdata%\Packages to find it faster on Windows.

Step 4 — Restart and play

Fully restart Minecraft, then go to Play → Worlds to find and open your map.

🗓️ Why Version Matters — And How to Match It

Older maps may use features or behaviours that were changed or removed in newer Minecraft versions. Always check the version listed on the map page before downloading.

How to install an older Minecraft version:

  • Android: Search for an older .apk from a trusted source like APKMirror, or use the Minecraft version history in the Google Play Beta program.
  • Windows: Open the Microsoft Store, go to your Minecraft library, and use "Manage" to access version history — or use Xbox App Game Manager.
  • iOS: Version switching on iOS is limited. Check if the version is still available through TestFlight or App Store history.

⚠️ Note: Always back up your existing Minecraft worlds before switching versions.

⚠️ Important Notes Before Playing

  • Make sure your Minecraft version matches the map's required version before installing.
  • Do not place the world folder inside another folder — it must be at the root level.
  • Ensure the file is fully extracted before moving it.
  • If the world doesn't appear, double-check the folder path and fully restart the game.

Troubleshooting

World doesn't appear in the list

Check that the folder path is correct and the folder is not nested. Restart Minecraft completely — not just minimize it.

Import failed or crashes

You're likely on the wrong Minecraft version. Check the map page for the required version and match it exactly.

Textures look wrong or missing

Some maps require a specific resource pack. Check the map's download page or description for any included addons, and make sure they're applied in World Settings.
